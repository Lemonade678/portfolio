# TheOzzy Card-Table Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/next` teaser with a full fan site for TheOzzy at `/ozzy`: a deck-style card table that opens six windows (profile, clips, run, wheel, collection, shop) over it, with a persistent points wallet, run-scoped relics, a mid-run merchant and clips pulled from his YouTube RSS feed.

**Architecture:** `app/ozzy/layout.tsx` renders a client `OzzyShell` that owns all state (run reducer, wallet/save, powder, music, language) and draws the table; each window is a child route rendered inside a `Window` dialog over the table, so state survives switching windows. Pure logic (RSS parsing, save parsing, game rules) lives in `lib/ozzy/*` and is unit-tested with vitest; the UI rolls dice/draws offers and passes the results into the reducer.

**Tech Stack:** Next.js 16 App Router · React 19 · TypeScript · Tailwind v4 · vitest (dev only) · Python + Pillow for asset prep

**Spec:** `docs/superpowers/specs/2026-10-08-ozzy-hub-design.md`

## Global Constraints

- No new runtime dependencies. `vitest` is the only new package (devDependency).
- Every user-visible string is `L10n` (`{ en, th }`); comments in Thai explain *why* (project convention).
- Ozzy colours stay scoped under `.oz` in `app/globals.css` — never added to `@theme`.
- Whole `/ozzy` zone is `robots: { index: false, follow: false }`.
- Copy never says the site is official, commissioned, or a partnership: only "งานชิ้นถัดไปของผมคือทำเว็บไซต์ให้เขา".
- YouTube iframes are created only after a user action, from `www.youtube-nocookie.com`, at least 200 px tall.
- Save key `ozzy:save:v1`; starter points **200** once per browser; points are integers ≥ 0.
- Relics: max **3** held, no duplicates in a run, bought only while a run is active (`playing` or `merchant`); merchant price = 80% rounded **down** to a multiple of 10.
- Respect `prefers-reduced-motion` (JS waits skipped, CSS durations already zeroed globally).
- 375 px wide viewport: no horizontal scroll anywhere in `/ozzy`.
- Source images stay in `tools/source/` (gitignored); only processed files under `public/ozzy/` are committed.
- Commit locally after each task; never push.

## Review Focus

1. **Cold deep link** (`/ozzy/run` opened directly, no prior visit): table renders behind, focus lands on the window heading, Esc/✕ go to `/ozzy` — browser check in Task 5.
2. **Storage blocked** (private mode or `setItem` throwing): site still playable, wallet just isn't remembered, no crash — unit test in Task 2 + browser check in Task 5.
3. **RSS down or slow** (bad URL / timeout): clips window shows featured clips + message, card number shows `0`, no error page — browser check in Task 8 via `OZZY_FEED_URL`.
4. **Rapid double clicks** on buy / roll / spin: never two purchases of one relic, never a 4th relic, never negative points — reducer tests in Task 3, disabled buttons in Tasks 6–7.
5. **Leaving a window mid-roll or mid-spin** and coming back: no stuck "rolling" state, music keeps playing, wallet consistent — browser check in Task 6 and Task 7.
