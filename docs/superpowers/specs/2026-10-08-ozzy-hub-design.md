# Spec: เว็บเต็มของ TheOzzy — โต๊ะไพ่ hub ที่ `/ozzy`

วันที่: 2026-10-08 · สถานะ: รอเจ้าของเว็บรีวิว
งานย่อย A จากคำขอ "ทำเว็บฉบับเต็มเป็น hub menu" (งานย่อย B = พอร์ตแบบ hub ทำ spec แยกทีหลัง — ดูท้ายเอกสาร)

---

## 1. เป้าหมาย

**สิ่งที่เจ้าของเว็บบอก**
- ทำเว็บฉบับเต็มให้ TheOzzy (สตรีมเมอร์เกมการ์ด/roguelike) เป็น **hub menu** — กดเมนูแล้วเปิดเป็น **หน้าต่างลอยบน hub**
- ใส่ **รูปหน้าตัวสตรีมเมอร์** (รูปถ่ายจริง 3 รูป) · ธีม **เกมการ์ด** · ใช้ **emote ของช่อง**
- มี **ระบบดึงคลิปล่าสุดจาก YouTube** + ไฮไลต์เกม + คลิปมีม
- มี **ระบบแต้ม** ซื้อของได้ และ **ซื้อรีลิคระหว่างเล่น** (อ้างอิงหน้า Channel Points ของช่อง)
- มี **ลิงก์โดเนท** `https://easydonate.app/theozzy`
- เลือกแล้ว: อยู่ในพอร์ตใต้ `/ozzy` · โต๊ะแบบ **B (หน้าจัดเด็ค)** · คลิปจาก **RSS** · เทสต์ด้วย **vitest**

**สิ่งที่สันนิษฐาน (ยังไม่ได้ยืนยันกับ Ozzy)**
- เป็นงานแฟนทำ ยังไม่ใช่เว็บทางการ — ถ้อยคำบนเว็บต้องไม่อ้างว่าทางการ/ได้รับว่าจ้าง
- รูปถ่ายทั้ง 3 รูปมาจากหน้าเพจสาธารณะของเขา เจ้าของเว็บเป็นคนให้มา — **ควรขออนุญาต Ozzy ก่อนดันหน้านี้ให้คนเห็นจริงจัง**

**สำเร็จเมื่อ**
- เปิด `/ozzy` เห็นโต๊ะไพ่: การ์ดฮีโร่ (รูปหน้า Ozzy) + ไพ่ 6 ใบ กดแล้วหน้าต่างลอยขึ้น ปิดได้ด้วย ✕ / Esc / ปุ่ม back
- ทุกหน้าต่างมี URL ของตัวเอง เปิดตรงจากลิงก์ได้ แชร์ได้
- คลิปล่าสุดอัปเดตเองภายใน 1 ชั่วโมงหลัง Ozzy อัปคลิปใหม่ โดยไม่ต้อง deploy
- เล่นดันเจี้ยน → ได้แต้ม → เอาแต้มไปซื้อรีลิคทั้งจากร้านและพ่อค้ากลางทาง → แต้มยังอยู่เมื่อกลับมาเปิดเว็บวันหลัง
- `npm run build` ผ่าน · `npm test` ผ่าน · ใช้งานได้บนมือถือ 375 px โดยไม่ล้นจอแนวนอน

## 2. โครงหน้า

### 2.1 Route

| URL | สิ่งที่เห็น |
|---|---|
| `/ozzy` | โต๊ะไพ่อย่างเดียว ไม่มีหน้าต่าง |
| `/ozzy/profile` | หน้าต่าง **โปรไฟล์** |
| `/ozzy/clips` | หน้าต่าง **คลิป** |
| `/ozzy/run` | หน้าต่าง **ดันเจี้ยน** |
| `/ozzy/wheel` | หน้าต่าง **วงล้อ** |
| `/ozzy/collection` | หน้าต่าง **คอลเลกชัน** |
| `/ozzy/shop` | หน้าต่าง **ร้านแต้ม** |
| `/next` | **redirect 308 → `/ozzy`** (ลิงก์เก่าที่เคยแชร์ยังใช้ได้) |

ภาษาส่งผ่าน `?lang=th` — ลิงก์ทุกอันในโซน `/ozzy` แนบ query นี้ต่อให้ (ถ้ากำลังเป็นภาษาไทย)

### 2.2 หน้าต่างลอยบนโต๊ะ (วิธีทำ)

- `app/ozzy/layout.tsx` (server component) วาด **`<OzzyShell>`** ซึ่งค้างอยู่ตลอดตอนสลับหน้าต่าง — Next.js ไม่ remount layout เมื่อเปลี่ยน route ลูก
- หน้าย่อยแต่ละหน้าคืน `<Window>` ที่ลอยทับโต๊ะ · `app/ozzy/page.tsx` คืน `null`
- ผลที่ได้: state ทั้งหมด (รัน แต้ม รีลิค แป้ง เพลง ภาษา) อยู่ที่ shell ไม่หายตอนสลับหน้าต่าง
- ไม่ใช้ parallel/intercepting routes — โต๊ะเป็น layout แม่อยู่แล้ว ไม่จำเป็น

### 2.3 โต๊ะไพ่ (แบบ B — หน้าจัดเด็ค)

```
┌ แถบบน (sticky) ─────────────────────────────────────────┐
│ ← พอร์ต        [♥♥♥ · ☘ 1,542 · 🧴×1 · 🎵]        TH|EN   │
├──────────────────────────────────────────────────────────┤
│ ┌─ การ์ดฮีโร่ ─┐   เด็คของ OZZY · 6 ใบ                     │
│ │  รูปหน้า     │   [โปรไฟล์] [คลิป]     [ดันเจี้ยน]          │
│ │  Ozzy       │   [วงล้อ]   [คอลเลกชัน] [ร้านแต้ม]          │
│ └─────────────┘                                          │
│  TheOzzy · เล่นเกมการ์ด คุยเรื่อยเปื่อย                        │
│  [☕ สนับสนุน Ozzy ↗]                                       │
└──────────────────────────────────────────────────────────┘
```

- **การ์ดฮีโร่:** รูปเซลฟี่ (ชัดสุด เป็นแนวตั้ง) ใต้การ์ดมีชื่อ คำโปรย (จากหน้าเพจเขา: "เล่นเกมการ์ด คุยเรื่อยเปื่อย") และปุ่ม **สนับสนุน Ozzy** → `easydonate.app/theozzy` (แท็บใหม่)
- **ไพ่ 6 ใบ** เป็น `<Link>` ธรรมดา (ใช้คีย์บอร์ดได้) ชี้แล้วยกขึ้น + ขอบทอง
  มุมซ้ายบนวงฟ้า = ลำดับไพ่ 1–6 · มุมขวาบนหกเหลี่ยมส้ม = **ตัวเลขจริง** ของหน้าต่างนั้น:

  | ไพ่ | รูปบนไพ่ | ตัวเลขมุมขวา |
  |---|---|---|
  | โปรไฟล์ | รูป Ozzy (สตรีม) | จำนวนรูป (3) |
  | คลิป | Dooley | คลิปที่ลงใน 7 วันล่าสุด (นับจาก RSS) |
  | ดันเจี้ยน | M'Baku | จำนวนห้อง (4) |
  | วงล้อ | ไอคอนวงล้อ | จำนวนช่อง (8) |
  | คอลเลกชัน | Pepe | จำนวน emote + ตัวละครที่โชว์ |
  | ร้านแต้ม | ไอคอนรถเข็น | จำนวนของในร้าน |

- จอกว้าง: ฮีโร่ซ้าย ไพ่ตาราง 3×2 ขวา · มือถือ: ฮีโร่บน ไพ่ 2 คอลัมน์
- สี: ชุดเดิมจากช่องเขา (`.oz` ใน `globals.css`) + เส้นหมึกการ์ตูน

### 2.4 หน้าต่าง (`<Window>`)

- กรอบการ์ด: แถบชื่อ (รูปไพ่จิ๋ว + ชื่อ + ยอดแต้มถ้าเกี่ยว + ปุ่ม ✕) · เนื้อหาเลื่อนในกรอบ
- โต๊ะข้างหลังมืด + เบลอ และใส่ `inert` (กด/โฟกัสไม่ได้ระหว่างหน้าต่างเปิด)
- `role="dialog"` `aria-modal="true"` `aria-labelledby` → หัวหน้าต่าง
- เปิด: ย้ายโฟกัสไปหัวหน้าต่าง · ปิด (✕ / Esc / back): กลับ `/ozzy` และคืนโฟกัสไปที่ไพ่ใบที่กดเปิด
- เปิดตรงจากลิงก์ (`/ozzy/run`) ได้ — โต๊ะวาดอยู่ข้างหลังเหมือนกดจากโต๊ะ
- มือถือ: หน้าต่างเต็มจอ
- เคลื่อนไหวตอนเปิด: ไพ่ยกขึ้นแล้วกางเป็นหน้าต่าง (CSS) · ลดการเคลื่อนไหว = เปิดทันที

## 5. ระบบหลังบ้าน

### 5.1 คลิปจาก RSS — `lib/ozzy/youtube.ts`
- URL: `https://www.youtube.com/feeds/videos.xml?channel_id=UCFTHMGDbsXFPMbfi1TCeBGw`
- `fetchFeed()` (server only): `fetch(url, { next: { revalidate: 3600 }, signal: AbortSignal.timeout(5000) })`
  ล้มเหลว → `{ ok: false, videos: [] }` ไม่ throw ออกไปถึงหน้า
- `parseFeed(xml): Video[]` **ฟังก์ชันล้วน** (เทสต์ได้) — ต่อคลิป:
  `id` · `title` (ถอด entity `&amp; &quot; &#39; &lt; &gt;`) · `published` (ISO) · `views` · `isShort` (ลิงก์มี `/shorts/`) · `thumb` · `game`
- `game`: ข้อความหลังเครื่องหมาย `-` ตัวสุดท้ายที่**ตามด้วยช่องว่าง** (regex `-\s+([^-]+)$`) ตัดอีโมจิ/ช่องว่าง เทียบกับตาราง
  — ไม่ใช้ ` - ` (มีช่องว่างสองฝั่ง) เพราะบางชื่อติดอีโมจิหน้าขีด เช่น `…ควงค้อน🔥- THE BAZAAR`
  `MARVEL SNAP → Marvel Snap` · `THE BAZAAR / The Bazaar → The Bazaar` · `Batomon Showdown` · `Size it up` · `TFT…→ TFT` · ไม่ตรง/ไม่มี → `อื่น ๆ`
- `weeklyCount(videos, now)`: จำนวนคลิปที่ `published` อยู่ใน 7 วันก่อน `now` (ใช้กับตัวเลขบนไพ่ "คลิป")
- `app/ozzy/layout.tsx` เรียก `fetchFeed()` เอาแค่ `weeklyCount` ไปให้ไพ่ · `app/ozzy/clips/page.tsx` เรียกเอาทั้งรายการ
  (cache เดียวกัน — Next.js รวม fetch ที่ URL ซ้ำกันให้)
- `next.config.mjs`: `images.remotePatterns` อนุญาต `https://*.ytimg.com/**` · เพิ่ม `redirects()` ของ `/next`

### 5.2 การเก็บข้อมูล — `lib/ozzy/save.ts`
- `localStorage["ozzy:save:v1"]` = `{ v: 1, points, runs, bestRank, powdered, vip, welcomed }`
- `parseSave(raw): Save` ฟังก์ชันล้วน — ไม่ใช่ JSON / field ผิดชนิด / ติดลบ / ไม่ใช่ตัวเลขจำกัด → ค่าเริ่มต้น
- อ่าน/เขียนครอบด้วย try/catch (โหมดส่วนตัว/บล็อก storage → เล่นได้ปกติแต่ไม่จำ)
- ไม่เก็บรันที่ยังเล่นอยู่และรีลิค (รีโหลด = เริ่มใหม่ ตามแบบ roguelike)

### 5.3 ตรรกะเกม — ย้าย `app/next/game.ts` → `lib/ozzy/game.ts` แล้วต่อยอด
- คงหลักเดิม: reducer + ฟังก์ชันล้วน ไม่สุ่มเอง (UI ส่งหน้าลูกเต๋า/ผลสุ่มพ่อค้าเข้ามา)
- state ใหม่: `relics: { id, used }[]` · `maxHp` · สถานะเพิ่ม `"merchant"` · `merchantOffer: RelicId[]`
- `resolveRoll(state, kind, d20, reroll)` — รับลูกเต๋าลูกที่สองไว้ใช้กับ "เสก"
- action ใหม่: `buyRelic` · `useBan` · `leaveMerchant` · `earn` (วงล้อ) · `spend` (ของสนุก)
- ราคา/ผลรีลิคอยู่ใน content (ไม่ hardcode ในหลายที่)

### 5.4 Shell (`OzzyShell`, client) — เจ้าของ state กลาง

- **กล่องเพลง** อยู่ที่ shell (มุมขวาล่าง · มือถือเต็มความกว้างด้านล่าง · สูง ≥ 200 px ตามข้อกำหนด YouTube · ปิดได้)
  → สลับหน้าต่างแล้วเพลงเล่นต่อ · iframe สร้างตอนสั่งเปิดเท่านั้น
- แผ่นแป้ง + ปุ่มล้างหน้า อยู่นอก `<main>` ของ shell (เหตุผลเดิม: `filter` ทำให้ `fixed` เพี้ยน)
- `document.body` พื้นครามระหว่างอยู่โซน `/ozzy` (เดิม)
