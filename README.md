## Deploy ขึ้น Vercel

**วิธีที่แนะนำ — ผูกกับ GitHub ให้ auto-deploy** (ไม่ต้องลง CLI ไม่ต้องยุ่งกับ token)

1. ~~สร้าง repo~~ ✅ [`Lemonade678/portfolio`](https://github.com/Lemonade678/portfolio)
   สร้างไว้แล้วและยังว่างสนิท → push ตรง ๆ ได้ ไม่ต้อง rebase ไม่ต้อง force
2. push โฟลเดอร์นี้ขึ้นไป (PowerShell):

   ```powershell
   git remote add origin https://github.com/Lemonade678/portfolio.git; git push -u origin main
   ```

   > PowerShell 5.1 **ไม่มี `&&`** ต้องใช้ `;` คั่นแทน ถ้าอยากให้คำสั่งหลังรัน
   > เฉพาะตอนคำสั่งแรกสำเร็จ ใช้ `cmd1; if ($?) { cmd2 }`

3. ไป [vercel.com/new](https://vercel.com/new) → **Import Git Repository** → เลือก repo นี้
4. Vercel ตรวจเจอว่าเป็น Next.js เอง **ไม่ต้องตั้งค่าอะไรเลย** — ไม่มี env var ที่ต้องใส่
5. กด Deploy

หลังจากนี้ push ขึ้น `main` เมื่อไหร่ Vercel จะ build ใหม่ให้อัตโนมัติ
และทุก branch/PR จะได้ preview URL ของตัวเอง

**วิธีที่สอง — ใช้ CLI** (ต้องล็อกอินผ่านเบราว์เซอร์ครั้งแรก)

```bash
npm i -g vercel && vercel
```

> **หมายเหตุเรื่องขนาด:** `public/models/yolo11n.onnx` หนัก 10.7 MB และ
> `public/lane-change-presentation.pdf` อีก 1.6 MB — ยังห่างจากลิมิตของ Vercel มาก
> แต่ถ้าวันหนึ่ง repo เริ่มอืด ให้ย้าย `.onnx` ไปโฮสต์ที่อื่นแล้วแก้ `DETECTOR.modelUrl`
> (อย่าใส่ใน `.gitignore` เฉย ๆ — Vercel build ไม่มี Python จะสร้างไฟล์ใหม่ไม่ได้)

## หลักฐาน (section 02) กับตัวแท็บ

`CREDENTIALS` ใน `content.ts` เก็บเอกสารจริงที่ตรวจสอบได้ ตอนนี้มีสี่ใบ เรียงตามแท็บ:
หนังสือรับรองสำเร็จการศึกษาจากสำนักทะเบียน มจธ. · ประกาศนียบัตรแฮกกาธอนจาก Generation Thailand ·
ใบรายงานคะแนน TOEIC 885 · สไลด์ปิดโครงการฝึกงานที่ Yuan Ze

**ฟิลด์ที่สำคัญที่สุดคือ `verifies`** เพราะมันบังคับให้เขียนว่าเอกสารนี้ยืนยันอะไร
ตัวอย่างที่ชัดที่สุดคือใบ certificate — บนใบเขียนแค่ว่า "เข้าร่วมและทำจนจบ"
ไม่ได้พิมพ์อันดับ 6/137 ไว้ (อันดับประกาศบนเวทีตอนปิดงาน)
ถ้าเอามาแปะเฉย ๆ คนอ่านจะเข้าใจว่าใบนี้รับรองอันดับด้วย ซึ่งไม่ตรงกับเอกสาร
และเป็นสิ่งที่ใครซูมดูก็จับได้ทันที — การ์ดเลยเขียนบอกไว้ตรง ๆ ว่าอันดับมาจากไหน

**ทำไมต้องเป็นแท็บ:** ใบ cert สัดส่วน A4 แนวนอน (1755×1241) สูงมากเมื่อกางเต็มความกว้าง
ถ้าเรียงเอกสารทุกใบต่อกัน คนต้องสกรอลผ่านรูปใหญ่ ๆ กว่าจะถึงส่วนถัดไป

ตัวแท็บทำตาม [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) ทั้งสองไฟล์:

| สิ่งที่ทำ | เพราะอะไร |
|---|---|
| `role="tablist"` / `role="tab"` / `role="tabpanel"` + `aria-controls` / `aria-labelledby` | screen reader อ่านออกว่าเป็นกลุ่มแท็บ ไม่ใช่ปุ่มลอย ๆ |
| `tabIndex` เป็น `0` เฉพาะแท็บที่เลือก ที่เหลือ `-1` (roving tabindex) | กด Tab แล้วข้ามทั้งกลุ่มไปเลย ไม่ต้องกดผ่านทีละใบ |
| ลูกศรซ้าย/ขวา + Home/End เลื่อนระหว่างแท็บ | เป็นวิธีที่คนใช้คีย์บอร์ดคาดหวังจากแท็บ |

ถ้าเพิ่มเอกสารใบใหม่ **แก้แค่ `CREDENTIALS` ใน `content.ts`** ตัว UI วนสร้างเองทั้งหมด
(แล้วตามไปเพิ่มใน `portfolio-preview.html` ให้ตรงกันด้วย)

## `tools/censor.py` — ปิดข้อมูลส่วนบุคคลก่อนขึ้นเว็บ

เอกสารจริงมีข้อมูลส่วนตัวติดมาเสมอ — ใบ TOEIC มีวันเกิด **เลขบัตรประชาชน 13 หลัก**
เลขอ้างอิง และบาร์โค้ด สคริปต์นี้ปิดให้ก่อนเอาขึ้นเว็บ ใช้ซ้ำกับเอกสารอื่นได้ ทำงานเป็นสามขั้น:

```bash
python tools/censor.py grid "C:/path/to/doc.jpg" -o grid.png        # 1. หาพิกัด
python tools/censor.py apply tools/recipes/toeic-885.json --preview # 2. ลองวางกรอบ
python tools/censor.py apply tools/recipes/toeic-885.json           # 3. ปิดจริง
```

พิกัดทั้งหมดเก็บใน recipe เป็น JSON ทำซ้ำได้ ไม่ต้องจำว่าเคยลากกรอบตรงไหน
(`input` ใน recipe ชี้ไปที่ไฟล์ต้นฉบับในเครื่องเจ้าของ — เครื่องอื่นรันซ้ำไม่ได้ ซึ่งตั้งใจ)

### ใบไหนเปิดอะไร ปิดอะไร

| เอกสาร | recipe | เปิดให้เห็น | ปิดไว้ |
|---|---|---|---|
| ใบคะแนน TOEIC | `toeic-885.json` | ชื่อ (พิมพ์ + เขียนมือ) · รหัสนักศึกษา (เขียนมือ มุมขวาบน) · คะแนน · วันสอบ | วันเกิด · ช่อง `ID Number` · เลขอ้างอิง `IJ…` · บาร์โค้ด |
| หนังสือรับรองสำเร็จการศึกษา | `degree-2026.json` | ชื่อ · รหัสนักศึกษา · สาขา · GPA · วันที่ | เลขที่หนังสือ (อว.) |
| ใบแสดงผลการเรียน (transcript) | — | **ไม่ขึ้นเว็บเลย** | มีวันเกิดกับเกรดทุกวิชา — ส่วนที่เว็บต้องใช้ (GPA) หนังสือรับรองบอกไว้แล้ว |

ชื่อกับรหัสนักศึกษาเปิดตามที่เจ้าตัวตัดสินใจ (ต.ค. 2026) — ชื่ออยู่บนหัวเว็บอยู่แล้ว
ปิดไปก็ไม่ได้ซ่อนอะไร แถมทำให้เอกสารดูเหมือนไม่ใช่ของเจ้าตัว

> ⚠️ **ช่อง `ID Number` บนใบ TOEIC ไม่ใช่รหัสนักศึกษา — เป็นเลขบัตรประชาชน 13 หลัก**
> รหัสนักศึกษาบนใบ TOEIC คือตัวที่เขียนมือไว้มุมขวาบน ส่วนใบหนังสือรับรองพิมพ์ไว้ในเนื้อความ
> ถ้าวันหนึ่งอยากเปิดข้อมูลเพิ่ม **ดูว่าช่องนั้นเก็บอะไรจริง ๆ ก่อน อย่าเดาจากชื่อช่อง**
> เลขบัตรประชาชนใช้ยืนยันตัวตนกับธนาคารและราชการ ติดเว็บไปแล้วเก็บคืนไม่ได้

### สามข้อที่สคริปต์นี้ยึด และเหตุผล

1. **แถบทึบ ไม่ใช่ blur** — เลขบัตรประชาชนมี 13 หลัก พิมพ์ด้วยฟอนต์ความกว้าง
   เท่ากันทุกตัว หลักแรกกับหลักตรวจสอบมีกติกาตายตัว การเบลอเหลือ "เงา" ของ
   ความเข้มกับความกว้างไว้พอที่จะไล่เดาทีละหลักหรือ deconvolve ย้อนกลับได้
   แถบทึบเขียนทับพิกเซลจริง ไม่มีอะไรให้กู้

2. **PDF ต้อง render เป็น bitmap ก่อนเสมอ** — วาดสี่เหลี่ยมทับบน PDF ตรง ๆ
   ข้อความเดิมยังอยู่ใน content stream ใต้สี่เหลี่ยมนั้น **ก๊อปวางออกมาอ่านได้เลย**
   เป็นวิธีที่หน่วยงานทำหลุดกันมาแล้วหลายครั้ง

3. **crop ปลอดภัยกว่าทาทับ** — พิกเซลนอกกรอบไม่ได้ถูกเขียนลงไฟล์เลย
   ใบ TOEIC จึงตัดครึ่งล่างที่มี `Name:` กับบาร์โค้ดยาวอีกชุดทิ้งทั้งแถบ
   แทนที่จะไล่ทาทับทีละจุด

## ของเล่น YOLO บนรูปโปรไฟล์

กดกรอบรูปโปรไฟล์ → โหลด `yolo11n.onnx` แล้ว **รัน inference จริงในเบราว์เซอร์**
วาดกล่อง `person 0.92` (บวก `cell phone` ถ้าคะแนนถึงเกณฑ์) ทับบนรูป

เหตุผลที่ทำ: หน้าเว็บ *เล่า* ว่าทำ computer vision ได้ — อันนี้ *แสดง* ให้ดูเลย
คนสาย CV เปิด devtools ดูได้ว่ามันโหลดโมเดลกับรันจริง ไม่ได้วาดกล่องหลอกไว้

| ขั้น | เกิดอะไรขึ้น |
|---|---|
| กดปุ่ม | inject `<script>` ของ `onnxruntime-web` จาก CDN (ไม่ต้อง `npm install`) |
| | สร้าง `InferenceSession` จาก `/models/yolo11n.onnx` แล้ว cache ไว้ที่ module scope |
| preprocess | letterbox รูปเป็น 640×640 เติมเทา `rgb(114,114,114)` → NCHW → หาร 255 |
| run | `session.run()` บน wasm (บังคับ 1 thread เพื่อเลี่ยง SharedArrayBuffer/COOP-COEP) |
| postprocess | อ่าน tensor `[1, 84, 8400]` แบบ `data[c * 8400 + i]` → ถอด letterbox → NMS แยกคลาส |
| วาด | กล่องเป็น `<span>` วางด้วย `%` จากพิกัดสัดส่วน 0..1 |

ทุกขั้นยกเว้น "วาด" อยู่ใน `lib/yolo.ts` — ห้องทดลองใน playground กับพิพิธภัณฑ์ใน `/stack` ใช้โมเดลก้อนเดียวกัน
(กดที่ไหนก่อนก็โหลดครั้งเดียว) · ส่วนคำนวณล้วน (`iou` · `nms` · `letterboxGeometry` · `decodeRaw` · `decode`) มีเทสต์

**ทำไมพิกัดแปลงเป็น % ได้ตรง ๆ:** `public/me.jpg` สัดส่วน 284:459 และกรอบบนหน้าเว็บ
ล็อก `aspect-ratio` ตัวเดียวกัน → `object-cover` ไม่ครอปซ้ำ เลยไม่ต้องคำนวณชดเชย

**ตอนโหลดโมเดลไม่ได้** จะ fallback ไปใช้ผลที่บันทึกไว้ใน `DETECTOR.fallback`
แล้ว **ติดป้ายบนปุ่มว่า `cached result`** ไม่เนียนว่าเพิ่งรันสด —
ทั้งเว็บขายเรื่องความซื่อสัตย์กับตัวเลข ตรงนี้ก็ต้องซื่อด้วย

### เปลี่ยนรูปโปรไฟล์ ต้องทำ 3 อย่าง

1. วางรูปทับที่ `public/me.jpg`
2. แก้ `DETECTOR.photoW` / `photoH` ให้เป็นขนาดจริงของรูปใหม่
   (**ข้อนี้ลืมบ่อยที่สุด** ลืมแล้วกล่องจะเพี้ยนไปคนละที่)
3. รันคำสั่งข้างล่างเพื่ออัปเดต `DETECTOR.fallback`

```bash
python -c "from ultralytics import YOLO; from PIL import Image; W,H=Image.open('public/me.jpg').size; r=YOLO('yolo11n.pt').predict('public/me.jpg',imgsz=640,conf=0.4)[0]; [print(f'{{ label: \"{r.names[int(b.cls)]}\", score: {float(b.conf):.4f}, box: [{b.xyxy[0][0]/W:.4f}, {b.xyxy[0][1]/H:.4f}, {b.xyxy[0][2]/W:.4f}, {b.xyxy[0][3]/H:.4f}] }},') for b in r.boxes]"
```

### สลับไปใช้โมเดลที่เทรนเอง (`Lemon(me):3`)

ตอนนี้ปุ่มนี้รัน `yolo11n` ซึ่งเป็น**โมเดลสำเร็จรูปของคนอื่น**
ถ้าเปลี่ยนไปใช้โมเดลจาก `lemon_detector/` จะกลายเป็น `Lemon(me):3 0.9x`
ต่างกันคนละเรื่องในสายตาคนดู — จาก "รันโมเดลเป็น" เป็น "เทรนโมเดลเป็น"

ทำตาม [`lemon_detector/README.md`](lemon_detector/README.md) จนถึง `python export_onnx.py`
สคริปต์จะพิมพ์บล็อกที่ก๊อปมาวางทับใน `DETECTOR` ได้เลย มี 4 ค่า:
`modelUrl` · `classNames` · `photoW`/`photoH` · `fallback`

**`classNames` คือตัวที่ลืมแล้วพังเงียบที่สุด** — ไม่ใส่แล้วเว็บจะถอยไปอ่านชื่อจากตาราง
COCO แล้วขึ้นว่า `person` ทั้งที่โมเดลตรวจถูกแล้ว (คลาส 0 ของ COCO ก็คือ person พอดี)
ตัวแรกในลิสต์ถือเป็นคลาส "พระเอก" ที่ UI เน้นด้วยสีเหลือง

`PhotoDetect.tsx` ไม่ต้องแก้ — `decode()` อ่านจำนวนคลาสจาก `dims[1]` ตามจริง
โมเดล 1 คลาสได้ tensor `[1, 5, 8400]` แทน `[1, 84, 8400]` แล้ววนลูปตามขนาดนั้น

### ข้อจำกัดของ gimmick นี้

- **10.7 MB** ที่ผู้กดปุ่มต้องโหลด (+ wasm อีก ~2 MB) — เลยออกแบบให้ *กดก่อนถึงโหลด*
- inference บน wasm 1 thread ใช้เวลา **~300–900 ms** ไม่ใช่ realtime
- คะแนนต่างจากที่รันด้วย ultralytics ราว 0.01 (canvas กับ OpenCV resize คนละวิธี) — กล่องต่างกัน <0.5% ของกรอบ
- ต้องเป็น **same-origin** ถ้าย้ายรูปไปโฮสต์อื่น `canvas.getImageData()` จะโดน taint แล้ว throw

## ไข่อีสเตอร์ — หน้า `/playground` (สปอยล์)

หน้ามุก "คุณเป็น xenogender แบบไหน?" ผลออกมาเป็น **Floralgender (ดอกมะนาว)**
เข้าได้ทางเดียวคือกดตัวอักษร **L E M O N A D E** ที่ซ่อนอยู่ในหน้าหลักให้ครบตามลำดับ จากบนลงล่าง

### ตัวอักษรอยู่ตรงไหน

ซ่อน **อยู่ในคำ** บนหน้าแรก หน้าตาเหมือนตัวหนังสือรอบข้างทุกอย่าง (เจ้าของเว็บอยากให้เป็นความลับจริง ๆ)
จุดสังเกตเดียวคือเอาเมาส์ไปชี้แล้วเคอร์เซอร์เป็นรูปมือ · กดถูกแล้วค่อยเรืองเหลือง
เลือกเฉพาะคำที่เหมือนกันทั้งสองภาษา — สลับภาษาแล้วตำแหน่งไม่เปลี่ยน · เรียงจากบนลงล่าง:

| ตัว | อยู่ในคำ | ที่ไหน |
|---|---|---|
| L · e | `[L]LM Fin[e]-tuning` | บรรทัดบทบาทใต้ชื่อ |
| M | `LL[M]` | ย่อหน้าแนะนำตัวแรก |
| o · n · a · d | `Generati[o][n] Th[a]ilan[d]` | การ์ดตัวเลขแฮกกาธอน (`secret: "hackathon"` ใน `METRICS`) |
| e | `lab[e]l` | บรรทัดใต้ตู้ขนม |

ตำแหน่งเก็บเป็น "คำ + ลำดับตัวอักษร" ใน `lib/secret.ts` (ไม่ได้ฝังเครื่องหมายไว้ในข้อความ)
**แก้ข้อความแล้วคำหายไป → `tests/home/secret.test.ts` แดง** และบนเว็บไข่จะหายเงียบ ๆ (หน้าไม่พัง)
ตัวอักษรเป็น `<span>` ไม่ใช่ปุ่ม — ไม่อยู่ในลำดับ Tab และ screen reader อ่านคำเต็มปกติ
(เจ้าของเว็บเลือกไม่มีทางเข้าด้วยคีย์บอร์ด) · มีพื้นที่กดล่องหนเพิ่มรอบตัวอักษรให้นิ้วบนมือถือกดโดน

### กติกา

- กดถูกตัว → ตัวนั้นติดไฟสีเหลือง
- กดผิดตัว (รวมถึงกดตัวที่ติดไฟไปแล้วซ้ำ) → เริ่มใหม่หมด
  ยกเว้นตัวที่กดผิดคือ L — นับเป็นตัวแรกของรอบใหม่เลย ไม่ต้องกดซ้ำอีกที
- ครบ 8 ตัว → รอ 450 ms ให้เห็นตัวสุดท้ายติดไฟ แล้วพาไป `/playground` ในภาษาที่เลือกอยู่

### ประตูหน้า playground

| ส่วน | ทำอะไร | ทำไม |
|---|---|---|
| `sessionStorage["lemonade:unlocked"]` | ตั้งเป็น `"1"` ตอนกดครบ | ปิดแท็บแล้วล็อกใหม่ — มาครั้งหน้าต้องหารหัสเองอีกรอบ ถ้าใช้ `localStorage` จะปลดครั้งเดียวค้างไปตลอด |
| `sessionStorage["lemonade:lang"]` | พาภาษาข้ามหน้า | ภาษาบนหน้าหลักเป็น state ใน React ไม่ได้อยู่ใน URL |
| gate สามสถานะ `checking → locked / open` | ตอนแรกเรนเดอร์หน้าว่าง | ตอน prerender บน server ยังอ่าน `sessionStorage` ไม่ได้ ถ้าโชว์หน้าล็อกไปก่อน คนที่ปลดแล้วจะเห็นหน้าล็อกแวบ ดูเหมือนรหัสไม่ผ่าน |
| `app/playground/layout.tsx` | `robots: noindex, nofollow` | ไม่อยากให้คนค้นชื่อแล้วเจอหน้านี้ก่อนเจอพอร์ต |
| พิมพ์ URL ตรง ๆ | เจอหน้าล็อกพร้อมคำใบ้ | คนที่ขยันเดา URL ก็สมควรได้ไปต่อ |

> **นี่คือการซ่อน ไม่ใช่ความปลอดภัย** — เนื้อหาทั้งหมดอยู่ใน JS bundle ที่ส่งไปทุกเบราว์เซอร์
> ใครเปิด devtools ตั้ง `sessionStorage` เอง หรืออ่านจาก bundle ตรง ๆ ก็เห็นหมด
> สำหรับมุกถือว่าพอ แต่ **ห้ามเอาของที่เป็นความลับจริงมาไว้หลังประตูนี้**

### เนื้อหา

ทุกบรรทัดอยู่ใน `PLAYGROUND` ท้าย `lib/content.ts` เป็น `L10n` ตามกติกาเดียวกับหน้าหลัก

- **ทำไม Floralgender ยังเป็นเรื่องมะนาว:** มะนาวทุกลูกเริ่มจากดอก เลยเลือกดอกมะนาวโดยเฉพาะ
  (ดอกตูมอมม่วง กลีบขาว เกสรเหลือง) หน้านี้จะได้ยังต่อกับรหัส LEMONADE และชื่อเล่น Lemon
  ส่วน Lemonadegender ที่เคยเป็นคำตอบ ถูกลดไปเป็นอันดับสอง (0.93)
- **ธงห้าแถบตั้งขึ้นเองสำหรับมุกนี้** ไม่ได้อ้างว่าเป็นธง floralgender ของชุมชนไหน
  ถ้าจะใช้ธงจริงของชุมชน ต้องไปหาที่มาให้ถูกก่อน
- **`detections` ต้องเรียงคะแนนจากมากไปน้อย** — UI ถือตัวแรกเป็นผู้ชนะ (ไฮไลต์เหลือง)
  ที่เหลือโชว์แบบ "ก่อนผ่าน NMS" ล้อกับที่ทั้งเว็บยืนยันว่าตัวเลขทุกตัวต้องมีที่มา

**ห้องทดลอง YOLO** (ท้ายหน้า): ผู้ชมเลือกรูปของตัวเอง → yolo11n ตีกล่องในเบราว์เซอร์ (รูปไม่ถูกอัปโหลดไปไหน)
→ คำตัดสินหนึ่งบรรทัดผูกของกินที่เจอเข้ากับชั้นในตู้ขนม (`lib/lab.ts`)
ของกินจริงชนะภาชนะ ภาชนะชนะช้อนส้อม/โต๊ะ (ทดลองกับรูปมื้อเย็นจริง โต๊ะได้คะแนนสูงกว่าแก้ว ถ้าไม่จัดขั้นคำตัดสินจะเป็น "โต๊ะ")
COCO ไม่มีคลาสมะนาวหรือต๊อก — มุกเลยใช้ของที่โมเดลรู้จัก (donut · cake · cup · bowl …)

**กติกาของมุกนี้: ล้อตัวเองได้ ห้ามล้อคนอื่น** — xenogender เป็นตัวตนจริงของคนกลุ่มหนึ่ง
และก็เป็น meme ที่ถูกเอาไปล้อเลียนคนกลุ่มนั้นบ่อย ทุกบรรทัดในหน้านี้เลยเป็นเรื่องของเจ้าตัว
(ชื่อ GitHub · ร้านต๊อก · YOLO) ไม่มีบรรทัดไหนบอกว่าแนวคิดนี้ไร้สาระ
และ footnote ท้ายหน้าบอกตรง ๆ ว่าทำด้วยความรัก — จะเพิ่มมุกใหม่ ให้ยึดหลักเดียวกัน

### ถ้าจะเปลี่ยนคำรหัส ต้องแก้ 3 ที่ให้ตรงกัน

1. `SECRET_WORD` ใน `components/SecretCode.tsx`
2. `SECRET_SPOTS` ใน `lib/secret.ts` ต้องมีครบทุก index ตั้งแต่ 0 ถึงความยาวคำ − 1 และตัวอักษรต้องสะกดคำใหม่ (แก้เทสต์ใน `tests/home/secret.test.ts` ด้วย)
3. ข้อความที่เขียนเลข 8 ไว้ตรง ๆ ใน `PLAYGROUND` — `unlocked` ("8 / 8") กับ `locked.body` ("Eight letters" / "8 ตัว")

**ข้อ 3 ลืมง่ายที่สุด** เพราะ TypeScript ไม่ฟ้อง เว็บจะยัง build ผ่านแต่คำใบ้โกหก

`portfolio-preview.html` **ไม่มีไข่อีสเตอร์นี้** — ตั้งใจ เพราะเป็นไฟล์เดียวเปิดด้วย `file://`
ไม่มี route ให้พาไป

## ลายเซ็นท้ายหน้า

วางต่อจากข้อความปิดท้าย ก่อนช่องทางติดต่อ — เหมือนเซ็นชื่อท้ายจดหมาย

| ขั้น | รายละเอียด |
|---|---|
| ต้นฉบับ | รูปที่เจ้าตัววาดเอง เส้นเหลืองมะนาวบนพื้นดำ เก็บที่ `tools/source/signature.jpg` (gitignore) |
| แปลง | `python tools/signature.py tools/source/signature.jpg` → `public/signature.png` พื้นใส 762×449 ~50 KB |
| วิธีแปลง | ความสว่างของพิกเซล → ค่าโปร่งใส ขอบเลยนุ่มเหมือนต้นฉบับ · ทาเส้นสีเดียว (`#EFF573` ค่ากลางจากต้นฉบับ) เพราะสีใน JPG เพี้ยนตามบล็อกบีบอัด · เปลี่ยนสีได้ด้วย `--color` |
| แสดงผล | เผยจากซ้ายไปขวาตอนเลื่อนมาถึง (clip-path) + แสงเรือง · คนที่ปิด animation เห็นเต็มทันที |

> **ข้อควรรู้ 2 ข้อ**
> 1. ลายเซ็นที่ขึ้นเว็บแล้ว ใครก็เซฟไปได้ — ถ้าเป็นลายเซ็นเดียวกับที่ใช้กับธนาคาร/สัญญา ควรรู้ไว้
> 2. `useReveal` ต้องจับที่ **กล่องครอบ** ไม่ใช่ที่ `<img>` — ตอนเริ่ม รูปโดน clip-path บังจนกว้างเหลือ 0
>    และ Chrome เอา clip-path ของตัว element ไปคิดตอนเช็กว่าเห็นหรือยัง ถ้าจับที่รูปตรง ๆ ลายเซ็นจะไม่เคยโผล่ (เคยพลาดมาแล้ว)

### ทำไมคลิป lane change เป็น WebP ไม่ใช่ .mp4

ไฟล์เอาต์พุตจาก pipeline เข้ารหัสด้วย
MPEG-4 Part 2 (mp4v) ซึ่งเป็นค่าเริ่มต้นของ `cv2.VideoWriter` และ **เบราว์เซอร์เล่นไม่ได้**
ต้องแปลงเป็น H.264 ก่อน ซึ่งต้องมี ffmpeg (เครื่องนี้ยังไม่มี) และ OpenCV บนเครื่องนี้
ก็เขียน H.264 ไม่ได้เพราะ openh264 DLL เวอร์ชันไม่ตรง —
animated WebP เลยเลี่ยงปัญหา codec ทั้งหมด เรนเดอร์เป็น `<img>` ธรรมดา
และไม่ติดนโยบายบล็อก autoplay ของเบราว์เซอร์ด้วย

ถ้าวันหนึ่งลง ffmpeg แล้วอยากได้ `.mp4` จริง ๆ:

```powershell
ffmpeg -i "D:\10-ไมเกี่ยวข้องงง\data6_new_output_good.mp4" -vf "scale=720:-2,fps=20" -an -c:v libx264 -crf 28 -movflags +faststart public/lane-demo.mp4
```

แล้วเปลี่ยน `<img>` ใน `page.tsx` เป็น `<video autoPlay muted loop playsInline>`
(ต้องมี `muted` ไม่งั้น browser บล็อก autoplay · ต้องมี `playsInline` ไม่งั้น iOS เปิดเต็มจอ)

> ⚠️ **ไฟล์วิดีโอต้นทางบางไฟล์เสีย** — `data4_new_output_good.mp4`,
> `data3_new_output_good.mp4`, `data2_new.mp4`, `data3_new.mp4` เปิดไม่ได้เลย
> (header/mdat ถูกตัด) ตัวที่ใช้อยู่คือ `data6_new_output_good.mp4` ซึ่งอ่านได้ปกติ

  และอย่าวางโปรเจกต์ในโฟลเดอร์ที่ sync (OneDrive/Dropbox)
